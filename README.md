# CloudBox

CloudBox — учебное консольное Java-приложение для хранения и управления файлами пользователей.

Проект создан для практики Java Core, SQL и JDBC с дальнейшим развитием в полноценное backend-приложение на Spring Boot.

## Возможности

- Регистрация пользователя
- Вход и выход из аккаунта
- Загрузка файлов в локальное хранилище
- Хранение метаданных файлов в PostgreSQL
- Просмотр списка файлов пользователя
- Скачивание файлов
- Переименование файлов
- Удаление файлов
- Автоматическое создание таблиц при запуске приложения

## Технологии

- Java 17
- JDBC
- PostgreSQL
- Docker Compose
- Java NIO Files API
- Custom Connection Pool

## Архитектура

Проект построен по слоистой архитектуре:

```text
CLI -> Service -> DAO -> Database
```

## Основные пакеты:

| Пакет       | Назначение                       |
| ----------- | -------------------------------- |
| `app`       | Точка входа в приложение         |
| `cli`       | Консольный интерфейс             |
| `service`   | Бизнес-логика приложения         |
| `dao`       | Работа с базой данных            |
| `model`     | Доменные модели                  |
| `dto`       | Объекты передачи данных          |
| `db`        | Подключение к БД и инициализация |
| `exception` | Пользовательские исключения      |

## Запуск

1. Запустить PostgreSQL:
```bash
docker compose up -d
```
2. Проверить настройки в application.properties.
3. Запустить класс:
```text
   com.lukyanovich.cloudbox.app.CloudBoxApp
```
## CLI-команды
| Команда    | Описание                 |
| ---------- | ------------------------ |
| `register` | Регистрация пользователя |
| `login`    | Вход в систему           |
| `logout`   | Выход из аккаунта        |
| `upload`   | Загрузить файл           |
| `list`     | Показать список файлов   |
| `download` | Скачать файл             |
| `rename`   | Переименовать файл       |
| `delete`   | Удалить файл             |
| `exit`     | Завершить приложение     |
